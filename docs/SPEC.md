# PhonePointer 仕様

## コンセプト
iPhoneを画面に向けて、空中でPCを操作するエアマウス。
iPhoneの向きでカーソルを動かし、手首のひねりでクリックする。スクロールは、画面に親指を置きながらiPhoneを傾けて操作する。

## 基本操作
| 操作 | 動作 |
|---|---|
| iPhoneを上下左右に向ける | カーソルを移動 |
| 手首を右にひねる | 左クリック |
| 手首を左にひねる | 右クリック |
| 画面に親指を置きながら手前に傾ける | 下にスクロール |
| 画面に親指を置きながら奥に傾ける | 上にスクロール |
| スクロール中に傾きを戻す | スクロール停止 |
| 画面から指を離す | カーソル操作に戻る |
| 中心合わせボタンを押す | 現在の向きを操作の基準にする |

スクロールは傾きが大きいほど速くする。親指を置いている間はカーソルを固定し、クリックのひねり操作も無効にする。

## システム構成
1. iPhoneアプリがセンサーから向きと回転を取得する。
2. 操作データをWi-Fi経由でPCアプリに送る。
3. PCアプリがカーソル移動、クリック、スクロールに変換する。

## 操作の補正
- クリック時の手ブレ補正: ひねり始めたときのカーソル位置を基準にクリックする。
- 中心合わせ: 現在の向きを基準にし直せるようにする。
- 感度調整: カーソルの移動量、クリックのひねりやすさ、スクロール速度を調整できる。
- 誤操作防止: 小さな手ブレではクリックやスクロールが発動しない。

## 初期版で検証したいこと
- ひねりクリックで狙った位置をクリックしやすいか、誤操作しないか。実機で判定・補正を調整する。
- ドラッグは画面上の「押している間ドラッグ」ボタンで行う。

## 決定事項(初期版)
| 項目 | 決定 |
|---|---|
| PCの対応OS | macOSのみ |
| 接続・ペアリング | Bonjour自動検出 + 初回のみMacに表示される4桁コード。承認済み端末は次回から自動接続 |
| 画面タップによる通常クリック | 補助操作として用意(設定でオフ可) |
| カーソル操作の一時停止 | 画面上の一時停止ボタン |
| 画面配置 | 上部の大きな領域 = スクロール/タップ領域。下部左 = ドラッグボタン、下部右 = 中心合わせ・一時停止 |
| 中心合わせの動作 | ジャイロ相対方式のため、押すとカーソルを画面中央に戻す |
